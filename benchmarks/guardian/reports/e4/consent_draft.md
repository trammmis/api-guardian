# API / 软件工程报告阅读实验知情同意说明（草案）

本研究比较两种 API incident / compatibility report 的呈现方式，了解软件工程师如何理解报告并选择下一步行动。完整流程预计约 60 分钟。

我们不会收集姓名、邮箱、雇主或其他不必要的身份信息。研究只记录匿名 participant ID、工程背景分级、每题答案、0–100 置信度、完成时间，以及 Clarity、Actionability、Helpfulness、Trust 的 1–5 分评分。

参加完全自愿。你可以在任何时间退出，不需要说明理由，也不会因此受到任何影响。退出前已提交的数据是否保留，将按正式确认的数据保留政策执行；在政策确认前不会开始正式收集。

数据只用于 API Guardian 项目评估。公开报告只展示汇总结果或无法识别个人的匿名结果，不公开个人原始答卷。
